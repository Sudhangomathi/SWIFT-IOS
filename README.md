# SWIFT-IOS

A repository covering Swift fundamentals for iOS development.

## Contents

- **[Start_with_the_basic_code_of_swift.swift](Start_with_the_basic_code_of_swift.swift)**: Basic `print()` statements, arithmetic expressions, variables (`var`), and constants (`let`).
- **[Swift_Conditional_Statements.swift](Swift_Conditional_Statements.swift)**: `if`, `if-else`, `if-else if-else`, nested `if` statements, and validation examples.
- **[Swift_loops.swift](Swift_loops.swift)**: `for-in` loop, `stride`, array iteration, `while` loop, `repeat-while` loop, and iOS examples.
